# ASTRID-Net: SE-Enhanced Triple Attention Deep Learning Framework for IoT and IIoT Security

## Short Detail
ASTRID-Net is a deep learning framework designed for high-accuracy intrusion detection in Internet of Things (IoT) and Industrial IoT (IIoT) networks. The model combines a Triple Attention Hybrid Architecture, which integrates Multi-Scale Convolutional Neural Networks (CNNs), Bidirectional Gated Recurrent Units (BiGRUs), and a combined channel-temporal attention mechanism, to identify cyber threats in real-time with superior accuracy.


## Key Features
- Triple Attention Mechanism: Combines channel, temporal, and spatial attention to prioritize the most relevant information for intrusion detection.
- Multi-Scale CNNs: Extracts spatial features from IoT and IIoT data, enhancing feature extraction across multiple scales.
- BiGRU: Captures temporal relationships, allowing the model to learn complex patterns in sequential data.
- Residual Learning: Improves model stability and facilitates faster convergence.

## Results
- Accuracy: 99.97% for binary and multiclass classification.
- Macro-Averaged Precision, Recall, F1-Score: Surpassing 99.97% on the Edge-IIoTset dataset.
- Outperforms conventional deep learning baselines for real-time cyber threat detection in IoT and IIoT environments.
